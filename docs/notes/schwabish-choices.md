- **B.** Schwabish. The first sentence is the opening statement, and the thanks come after it.

### 10. The three shapes

My reading of the three shapes:

- **The asymmetric hourglass**, the default. The opening states the result. The body gives the evidence.
  The end gives the reason for the result, as a payoff. Example: "We fixed the slow search" at the start,
  and "The index was rebuilt every night" at the end.
- **The symmetric hourglass**, for a talk with a call to action. The same message opens and closes the
  talk. Example: "Adopt the cache", then the evidence, then "Adopt the cache".
- **The funnel**, for a story. It opens with the problem and builds to the result.

The worksheet picks the shape with two questions. Does the talk build tension? Does it ask for an action?

My recommendation is this reading. Correct the asymmetric hourglass if I have it wrong.

### 14. Who fixes htmpres

htmpres lacks several things that the notes ask for:

- **Math.** It does not typeset math at all, because it runs Pandoc without MathJax or KaTeX.
- **Text in step with code or an equation.** All text steps run first, then all code steps. Text set to
  dim also greys out when code steps start.
- **Levels of importance.** There is no scale. The nearest are the classes `.lead` and `.callout`.
- **Links to appendix slides.** Appendix slides count as ordinary slides, and a link inside the deck does
  not move the slide.
- **Footnotes.** Their ids repeat from slide to slide.
- **Emphasis in titles.** It shows as literal asterisks.

It already does layering well. With `data-fragment-effect="dim"`, earlier points grey and later ones stay
hidden, as Schwabish asks. Code steps grey the other lines. Columns, split panes, full-screen pictures
with text, and section dividers all work.

- **A.** The skill uses only the syntax that htmpres has now. I write the gaps as issues for htmpres, and
  I do not change htmpres in this work.
- **B.** I fix htmpres in this work too, starting with math.

My recommendation is A. htmpres is another repository, and the guide can name the gaps.
